# KANINE KOMBAT - Controls

## Player 1

| Action | Key |
|---|---|
| Move Left | `A` |
| Move Right | `D` |
| Jump | `W` |
| Crouch | `S` |
| Block | `H` |
| Punch | `J` |
| Kick | `K` |
| Special | `L` |

## Player 2

| Action | Key |
|---|---|
| Move Left | `Arrow Left` |
| Move Right | `Arrow Right` |
| Jump | `Arrow Up` |
| Crouch | `Arrow Down` |
| Block | `4` |
| Punch | `1` or `Numpad 1` |
| Kick | `2` or `Numpad 2` |
| Special | `3` or `Numpad 3` |

## Character Select

| Action | Key |
|---|---|
| P1 Select Left / Right | `A` / `D` |
| P1 Confirm | `J` |
| P2 Select Left / Right | `Arrow Left` / `Arrow Right` |
| P2 Confirm | `1` or `Numpad 1` |
| Return to Title Screen | `Esc` |
| CPU Opponent in `VS CPU` | Auto-selects and auto-confirms |

## Battle Plan Stepper

| Action | Key |
|---|---|
| Start Next Match | `Space` |
| Pause Route Screen | `Esc` |

## Pause Flow

| State | `Esc` Behavior |
|---|---|
| Title Screen | No effect |
| Character Select | Return to title screen |
| Fight | Open pause overlay |
| Battle Plan Stepper | Open pause overlay |
| Pause Overlay | Resume current session |

The pause overlay also lets you switch directly to `2 PLAYER`, `VS CPU`, or `BATTLE PLAN`.

## Mouse / UI

| Action | Input |
|---|---|
| Start 2-player match | Click `2 PLAYER` |
| Start CPU match | Click `VS CPU` |
| Start Battle Plan | Click `BATTLE PLAN` |

## Post-Match

| Action | Key |
|---|---|
| Return to character select after Game Over | `Space` |
