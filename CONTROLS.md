# KANINE KOMBAT - Controls Reference

## Player 1

| Action  | Key       |
|---------|-----------|
| Move Left  | A      |
| Move Right | D      |
| Jump       | W      |
| Crouch     | S      |
| Block      | H      |
| Punch      | J      |
| Kick       | K      |
| Special    | L      |

## Player 2

| Action  | Key           |
|---------|---------------|
| Move Left  | Arrow Left   |
| Move Right | Arrow Right  |
| Jump       | Arrow Up     |
| Crouch     | Arrow Down   |
| Block      | 4            |
| Punch      | 1 (or Numpad 1) |
| Kick       | 2 (or Numpad 2) |
| Special    | 3 (or Numpad 3) |

## Character Select

| Action  | Key |
|---------|-----|
| P1 Select Left/Right | A / D |
| P1 Confirm | J |
| P2 Select Left/Right | Arrow Left / Arrow Right |
| P2 Confirm | 1 (or Numpad 1) |
| CPU Opponent | Auto-selects and auto-confirms in `VS CPU` mode |

## Special Controls

| Action        | Key   |
|---------------|-------|
| Return to Character Select (Game Over) | Space |
| Start 2-Player Game | Click `2 PLAYER` |
| Start CPU Match | Click `VS CPU` |
| Start Battle Plan | Click `BATTLE PLAN` |

## Input Tips

- **Blocking:** Hold block before attack connects
- **Combos:** Chain attacks quickly for bonus damage
- **Special:** Requires full meter (bar glows when ready)
- **Crouch:** Reduces hitbox, enables low attacks
- **Jump:** Avoids ground attacks, enables aerial positioning
- **Character Choice:** Controls stay tied to the player side, not to a specific fighter
- **Battle Plan:** Player 2 is CPU-controlled across a routed series of matches
